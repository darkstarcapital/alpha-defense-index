## Development

Prefer working locally? The project is plain HTML, CSS and JavaScript with no build step, so any static file server runs it.

```sh
git clone <this-repository-url>
cd <repository-name>
npx serve .
```

Projects with a backend keep it in the `workers/` folder. Deploy those files to Puter as workers first, following the [Puter Workers docs](https://docs.puter.com/Workers/).
